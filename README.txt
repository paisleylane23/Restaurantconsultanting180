RESTAURANT CONSULTANTS 360 — WEBSITE FILES

Included:
- index.html: website content
- styles.css: responsive design
- script.js: mobile navigation and email inquiry form

Preview locally:
1. Extract the ZIP.
2. Open index.html in a browser.

Publish free with GitHub Pages:
1. Create/sign in to a GitHub account at https://github.com
2. Create a new public repository named: restaurantconsultants360
3. Upload index.html, styles.css, and script.js to the repository's root.
4. Open repository Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
6. GitHub will provide a free address similar to https://YOUR-USERNAME.github.io/restaurantconsultants360/

Notes:
- The free address uses your GitHub username. It is not a purchased custom .com domain.
- The contact form prepares an email using the visitor's email app; it does not store submissions or send them automatically. Replace the mailto behavior with a form provider for hosted lead capture.
- Digital products are marked “Coming Soon”; checkout/product delivery needs to be connected before selling.
- The hero and team imagery load from Unsplash and require an internet connection.
- Review all copy, service details, and contact information before publishing.
